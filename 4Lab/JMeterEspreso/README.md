# Лабораторна робота №4 — тестування продуктивності з JMeter

Варіант 4: [espreso.tv](https://espreso.tv/). Потрібні Java 21 і JMeter 5.6.3 у `C:\soft`.

```
Open-GUI.bat                    план у графічному JMeter
Run-Test.bat                    консольний прогін: 5 читачів по 3 візити
Run-Test.bat 1 1 example.com    чужий сайт, усі перевірки падають
```

Навантаження навмисно мале: сайт чужий, сильне навантаження без дозволу
власника є атакою на відмову в обслуговуванні.
